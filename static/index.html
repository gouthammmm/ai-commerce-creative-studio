03

Live Admin API adapter

Checking connection…

The deployed server obtains a short-lived Shopify token and fetches products through Admin GraphQL. Credentials never reach the browser. The current connection is read-only and scoped to product data.

GET /api/shopify/live/status
GET /api/shopify/live/products?first=12

The development store currently returns three fictional AURA LIVING draft products. No customer/order access or payment processing is connected.

01

About AURA LIVING

FICTIONAL BRAND

AURA LIVING is an imagined home-decor studio built to explore how a premium product brand can feel considered across the storefront, product detail, campaign copy and advertising formats.

The visual direction leans on warm natural light, tactile interiors, a restrained color palette and clear product information. The photos are licensed Unsplash assets; brand, product names, copy and interface are independent practice work.

This prototype is not a client store or deployed Shopify theme. Shopify Liquid files are examples for theme conversion and the local API is a mock integration.
